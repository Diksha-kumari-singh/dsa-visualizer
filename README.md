# 🚀 DSA Visualizer

This project helps visualize Data Structures and Algorithms in an interactive way.

## ✨ Features
- Sorting Algorithms (Bubble, Merge, Quick, Insertion)
- Searching Algorithms (Linear, Binary)
- Graph Algorithms (BFS, DFS)
- Speed Control & Step-by-step visualization

## 🛠️ Tech Stack
- React
- Node.js
- Express
- MongoDB

## ⚙️ Run Project

Frontend:
npm run dev

Backend:
node server.js
